# Krishna Sanjeevani Calm

You are an award-winning Senior Product Designer from Apple, Spotify, Calm, and Headspace.

Design a COMPLETE production-ready mobile-first React PWA UI/UX for a premium therapeutic audio streaming platform called **Krishna Sanjeevani**.

This is NOT a music app like Spotify.

It is a therapeutic, wellness, meditation, and healing audio platform that streams Krishna Sanjeevani ragas and surāvalis for emotional wellness, stress relief, sleep improvement, focus enhancement, pregnancy support, and spiritual wellbeing.

The interface must feel:

• Apple-level polish

• Calm app aesthetics

• Headspace simplicity

• Spotify-quality streaming UX

• Modern SaaS dashboard quality

• Premium healthcare application

• Elegant

• Soft

• Minimal

• Spacious

• Luxurious

• Accessible

Avoid flashy gradients, loud colors, glassmorphism everywhere, neon colors, or gaming UI.
